# Editorial live photo clock — art direction

Source: user-provided collage screenshot, genuine photographs and genuine cloud video.

Reference: **editorial flat cut-photo montage**, 12 square/portrait photos forming one continuous jagged clock-like circle. All 12 neighboring photo pairs (including 12→1) must overlap in area. White sketch-marker numerals directly on photos, white thin freehand pen clock hands, no dropshadows, bevels, rounded cards, embossing or simulated 3D. Central negative space stays open.

Color: desaturated blue-charcoal moving clouds as secondary visual structure; distribute high-saturation warm red / pink / orange / yellow photograph accents among muted, neutral, blue photos. Adjust tile brightness and saturation per photo without distorting subject identity. Favor a continuous ring and asymmetric-but-balanced visual rhythm over mechanically even spacing. Design principles: Adobe color contrast, hierarchy, Gestalt closure / continuation.

Runtime: actual local time via browser `new Date()`; continuous requestAnimationFrame updates, including seconds hand. Actual muted cloud footage (not AI replacement), loop and inline autoplay on iOS with touch/resume retry.

GitHub README cannot run JavaScript. Link to separately deployed real-time HTML from project README. Use `live.html?v=3` to avoid stale site cache.
