02 / System pipeline

See. Describe. Speak.

One of the thesis's important design questions was that a user with low vision might not know whether an image is sufficiently sharp to support visual understanding. The system therefore integrates image restoration before visual description and speech interaction.

01 / INPUT

Image restoration

DeblurGAN helps prepare photographs affected by blur for subsequent recognition.
